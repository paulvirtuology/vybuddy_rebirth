Exemple d'intégration du widget VyBuddy Chat

Bienvenue sur le portail Vygeek

Cette page est un exemple d'intégration du widget de chat VyBuddy. Le bouton de chat apparaît en bas à droite de l'écran.

💡 Astuce : Cliquez sur le bouton de chat en bas à droite pour ouvrir le widget. Si vous n'êtes pas connecté, vous verrez d'abord le bouton "Continuer avec Google".

Contrôle programmatique

Vous pouvez contrôler le widget via JavaScript :

Après avoir détruit le widget, rechargez la page pour le réinitialiser.

Code d'intégration

Pour intégrer ce widget dans votre propre portail, ajoutez ce code :

<!-- Widget VyBuddy Chat --> <script src="https://chatbot.vygeek.com/chat-widget.js"></script> <script> VyBuddyWidget.init({ chatbotUrl: 'https://chatbot.vygeek.com', position: 'bottom-right', buttonColor: '#6366f1', buttonSize: 'large' }); </script>

Note : Remplacez https://chatbot.vygeek.com par l'URL de votre environnement chatbot.

Options de configuration

Vous pouvez personnaliser le widget avec ces options :

VyBuddyWidget.init({ chatbotUrl: 'https://chatbot.vygeek.com', // URL de votre chatbot (requis) position: 'bottom-right', // 'bottom-right', 'bottom-left', 'top-right', 'top-left' buttonColor: '#6366f1', // Couleur du bouton (hex) buttonSize: 'large', // 'small', 'medium', 'large' zIndex: 9999 // Z-index du widget });
